# assets/

Images used by the repository's own documentation. Nothing here ships into a user's
project, and skills never read from this folder.

| File | Used by | Notes |
|---|---|---|
| `banner.png` | `README.md` header | 2172 × 724 PNG. Keep the aspect ratio near 3:1 if you replace it, so the README header doesn't jump. |

Binary files here are marked `binary` in `.gitattributes`, so line-ending
normalization never touches them. Example images for the golden tests live with their
examples under `references/examples/`, not here.
